## 📌 Internship Tasks

### Task 1: Student Grade Tracker
A console-based Java application to input and manage student grades.

**Features:**
- Enter student names and grades
- Store student data using ArrayList
- Calculate average grade
- Find highest grade
- Find lowest grade
- Display a student grade summary

A console-based Java application that simulates a basic stock trading environment.

**Features:**

- Track user balance
- Manage stock portfolio
- Calculate portfolio value
- Record transactions

**Concepts Used:**

- ArrayList

- Scanner
